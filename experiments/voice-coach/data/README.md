# Synthetic voice-check coaching data, version 2

Generated by `../generate_dataset_v2.py`, using split-specific random seeds and templates. This data was designed **after examining errors on the original synthetic test split**: it increases coverage of combinations where the first model confused normal or clipped recording levels with a low level. The existing `../data/test.jsonl` is preserved as a prior exposed stress set. Do not report results on it as an untouched or independently sampled test.

Training includes every combination of transcript availability, recording-quality category, and pause-count bucket (18 combinations). Validation and test also include all 18 combinations, with split-specific wording and independent random draws. The generator verifies no exact input object appears in more than one split. These are interpolated tests within the same synthetic process: different input values and templates do not establish out-of-distribution generalization.

All measurements and responses are synthetic, rule-generated examples. They do not come from learner recordings, human teachers or experts and must not be represented as such. Formatted fields use the same metric names and ranges as Voice check; the explicit `pronunciation_assessed: false` is a synthetic scope marker the prompt assembler must add. Responses do not diagnose pronunciation or assign grades. Pace depends on transcript accuracy and detected audio; recording level/clipping does not measure a person's pronunciation.

The samples are deliberately narrow and templated. They are suitable for an initial feasibility experiment, not evidence of reliability across real microphones, noise, dialects, disabled speakers, or individual educational needs. Validate on separately collected, consented, human-reviewed real audio and reference feedback before making such claims. Test data was produced only after prior experiment findings and must be described accordingly.
